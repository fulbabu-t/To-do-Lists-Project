# 📝 My To-Do List App

A simple and clean To-Do List web application built using **HTML, CSS, and JavaScript**.  
It helps users manage daily tasks easily.

---

## 🚀 Features

- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- ❌ Delete tasks  
- 🎨 Simple and modern UI  
- 💾 Local storage support *(optional)*  

---

## ▶️ How to Run

1. Clone or download this repository  
2. Open the project folder  
3. Open `index.html` in your browser  

Or use Live Server in VS Code:


---

## 💡 Usage

- Type a task in the input field  
- Click **Add** to add it  
- Click the circle to mark it as complete  
- Click **X** to delete the task
